3In left sidebar → Build → Realtime Database → Create Database → Start in test mode → Enable
4Copy the database URL shown — looks like: https://carecay-bms-xxxx-default-rtdb.firebaseio.com
5Paste URL below → Click Connect → Click Push ↑ → Done! Both PCs now sync in real-time ✅
